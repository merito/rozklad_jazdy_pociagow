# Rozkład jazdy pociągów (Train Timetable) for PebbleOS

![Rebble store screenshots][./docs/rebble_store_screenshots.png]

The app shows the closest stations and departures with delays, platform and track numbers. It consumes an unofficial [API Bilkom](https://kalkulatorkolejowy.pl/bilkom). The app bases on [PebbleRail](https://github.com/jccit/pebblerail).

[Link to the Rebble Store](https://apps.rebble.io/en_US/application/68a759a7652aec0009f26c41)
